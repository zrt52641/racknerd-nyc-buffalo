## 实测数据：延迟、三网路由和速度

先给结论：三网往返直连，没有绕路欧洲的情况；到国内平均延迟约 241ms，三网普遍落在 230–250ms 区间，电信基本在 240ms 上下，移动稍微好一点，联通差不多。比西海岸节点高 60–80ms，这是物理距离决定的，跨太平洋再加横穿美国本土，哪个东海岸机房都绕不开。

公开测评里测试的是入门款机器：1 核 / 512MB 内存 / 10GB SSD / 1TB 月流量 / 1Gbps 带宽，KVM 虚拟化。处理器为 E5-2680v2，单核 2.80GHz，性能算不上强；内存实际可用 487M，另分配了 511M 虚拟内存；硬盘平均读写测到 805MB/s，这部分表现不错。另一份偏配置汇总的指南里，磁盘 IO 测出来在 250MB/s 左右，UnixBench 跑分 500 出头。不同批次、不同套餐数字会有差异，当个参考区间看就行。

三网路由的具体走向（来自公开测评）：

- **电信**：去程经圣何塞直连进美国，再到纽约；回程同样经圣何塞直连回国。
- **联通**：去程走洛杉矶直连，途经节点不多；回程直连。
- **移动**：去程经洛杉矶直连，再转美国国内几个节点到纽约；回程从西雅图直连。

速度方面，电信节点的上传下载都在 500Mbps 以上，联通也在 300Mbps 以上；用本地 100M 移动带宽看 YouTube 4K 很流畅，测速值能跑到 7 万多。测评作者认为这和纽约节点国内用户少、线路不挤有关系。两份测评的机器都手动装了原生 BBR，KVM 架构下操作没有障碍。稳定性上，英文评测站对自家测试机（洛杉矶节点）半年监测记录到 99.93% 的在线率，期间只有两次短暂中断，纽约节点可以参考这个运营水平，但没有同口径数据。

短板有两个。一是 Cogent 线路高峰期的稳定性一般，这是廉价大带宽线路的通病；二是流媒体解锁，带宽够看视频和解锁奈飞是两回事，这个节点对奈飞的解锁能力一般，有解锁需求的看西海岸。

## 常见问题

**纽约 VPS 支持退款吗？**
不同来源说法不一：一份详细整理里提到官方口径是「不退款，但保证帮你解决问题到满意为止」，早年的社区测评也提醒过便宜套餐不支持退款；2026 年更新的英文评测站则标注了 72 小时退款保障。稳妥的理解是别把退款当退路，下单前先用测试 IP 验证延迟。支持渠道以工单和邮件为主，遇到问题先开工单别急着点取消——后台取消服务 24 小时后会自动停服并清空数据。从公开反馈看，工单响应算快的。

**纽约节点支持 IPv6 吗？**
目前不支持。RackNerd 的洛杉矶和法国节点支持 IPv6（开工单申请，最多 100 个免费地址），纽约节点还在扩展中，有需要的下单前先问客服确认。

**买完能换机房吗？**
不能。只能新开一台同套餐再手动迁移数据，所以下单时 Datacenter 一定选对。

**能升级配置吗？**
能升不能降。升级在控制面板直接操作到更高一档，重启生效，停机一分钟左右；降级不支持，只能新开迁移。
